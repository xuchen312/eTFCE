# eTFCE 
**Exact Threshold-Free Cluster Enhancement via Fast Cluster Retrieval**





## Notes

This repository currently provides an example for a one-sample t-test using sign flipping.

The underlying computational framework is general and can be extended to other designs (e.g., two-sample tests or regression models), but these are not included here for simplicity.
